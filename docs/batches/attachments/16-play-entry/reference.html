One guided play entry

From this checkout, run:

python3 tools/play.py

Choose one action: current-map briefing, new duel collection, deliberate duel draft editing, sequence assembly, assessment of a selected duel, assessment of a selected sequence, or quit. Each invocation performs one action and exits. Menus and context questions go to stderr. Stdout remains the existing tool's normal text or plain JSON, suitable for redirection. The same buffered input stream serves the launcher and delegated helper, including assistant-supplied batched stdin. No shell command is constructed.

Map entry asks for actual chapter, difficulty, turn and phase, then discloses Tactical spoilers as the blank-answer default. Choose No spoilers or Full information explicitly to override it, and text, provenance or details for the view. The briefing owns scope filtering, supported modes and phase interpretation. The launcher never selects a run or guesses context.

Collection and editing ask for an optional new local output before delegating. Blank means stdout only. Existing values need deliberate reuse and a fresh overall confirmation; catalog weapons also need a fresh exact match confirmation. The existing helper refuses overwrites and unsafe destinations. Sequence assembly retains its distinct-entity selection and three independent confirmations. No observations, effects or unsupported fields are rewritten to obtain numbers.

Assessments explicitly select either a duel or a sequence JSON file. Named current_run.json paths, symlinks resolving to that name and hardlinks to this checkout's standard run are refused before opening. Run-shaped JSON and selecting the wrong observation kind are also refused. The launcher does not open a live run or ledger, initialize an army, import state or update tracking. The selected duel gate or sequence engine owns calculations and warnings. Exit 0 and valid JSON do not establish supported input or map safety: inspect UNKNOWN, limitations and conditional results.

Type cancel, send EOF or press Ctrl-C at a launcher prompt to exit 2 without starting an action. Invalid selections also exit 2; quit exits 0. Once delegated, the selected helper owns cancellation, errors and its actual exit status (the duel collector cancels with 1, sequence assembly with 2). No second action or automatic retry follows. Redirected stdout can be empty after cancellation.
