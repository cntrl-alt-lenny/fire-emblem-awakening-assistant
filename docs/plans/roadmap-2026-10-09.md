# Product roadmap — 2026-10-09

This is a proposed sequence, not an owner decision to redesign or launch.
Batches 08/09 are complete on main; the project remains unfinished.
Baseline: `e78fa7bcc245071556a408f725105ac63ce7a8e9`.

## Product goal

An offline companion for actual Awakening play: read the current map, enter
observed combat inputs, understand supported risk, and retain the player's army
history. Value comes from useful decisions with fewer manual steps and honest
unknowns. More tests, source rows and framework documents are not user outcomes.

## Current capability and limits

| Area | Available | Important limit |
|---|---|---|
| Reference | 49 characters, 55 class variants, 138 weapons, 103 skills | Mostly single-source; catalog breadth is not independent verification |
| Calculations | Supported duels, growths, forging, Pair Up bonuses, selected EXP/staff cases | Several procs/full dual outcomes refused; eligibility separate |

## Milestones

1. **Reliable daily workflow:** deliver the three batches; add observation entry
   assistance after a short synthetic trial establishes the desired interaction.
   Compare existing 333-line map and 142-line duel outputs with concise results.
2. **Usable alpha:** one offline entry point or local interface, chosen after
   workflow testing; ten representative synthetic tasks completed without manual
   JSON editing, with zero unknown-to-safe conversions or history/spoiler loss.
   Proposed target: at least 8/10 tasks without Brain intervention. Report time
   and input burden before/after; then validate one consenting real play session.
3. **Evidence depth:** promote specific claims only after difficulty/phase/version
   evidence. Start with a bounded map; parked Chapter5/17/20 need observational
   evidence, not another guide-comparison cycle. Coverage does not rise for UX work.
4. **Broader release:** prioritize unsupported mechanics by actual demand, then
   broader modes, portability, license choice and distribution. Full route safety
   is a separate research goal, not an alpha promise.
