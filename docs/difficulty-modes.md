# Difficulty and game mode

Normal, Hard, Lunatic and Lunatic+ remain separate keys in every map record. No enemy stats are borrowed between them. Character recruitment variations labeled Hard/Lunatic are preserved; Lunatic+ templates remain explicitly unknown rather than asserting unsourced equivalence.

Sources `gamerguides_modes` and public map excerpts describe Hard and above reinforcements acting during their arrival enemy phase. Normal arrival gives a response opportunity. This is a timing rule, not a map schedule; location, trigger, blockers and wave count remain map-specific. Always inspect actual enemies.

Lunatic+ additionally assigns random enemy skills. `fandom_lunatic_plus` describes early pool Pass, Vantage+, Luna+, Hawkeye, then Pavise+, Aegis+, Counter after Chapter2. The source is a stub/search excerpt; actual skills matter more than a generic pool. Enhanced skills differ from similarly named ordinary skills. The combat tool supports a selected isolated subset of the enhanced skills; Counter and some interactions remain refused. Full Lunatic+ map/skill-roll coverage is unresolved.

Classic defeat normally removes a unit permanently. Casual (EU manual: Newcomer) units retreat for the current map and return after its completion. Chrom/Robin defeat can cause game over in either mode. Never assume a reset. Tracker `death` follows selected mode; `complete-map` records Casual recovery explicitly. Difficulty and Classic/Casual are different axes.

Enemy-stat differences, AI changes, world-map encounter scaling and detailed Lunatic EXP behavior are incomplete. See uncertainties; no general multiplier converts Hard stats into Lunatic stats.
